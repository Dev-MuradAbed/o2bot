# بوت واتساب مطعم O2

بوت واتساب (Baileys) + لوحة تحكم، مع نظام صلاحيات وسجل تغييرات لحل مشكلة توفّر الأصناف.

دليل الرفع الكامل في **[SETUP.md](SETUP.md)**.

---

## المشكلة التي يحلّها الإصدار الحالي

الكاشير لا يعرف أن صنفاً نفد فيبيعه ثم يعتذر للزبون. الآن:

1. أي موظف يغلق الصنف من اللوحة أو بأمر واتساب واحد.
2. البوت يتوقف فوراً عن عرضه ويقترح بدائل من نفس القسم.
3. الكول سنتر والكاستمر كير يرون نفس الحالة لحظياً.
4. السجل يُظهر من أغلق، وماذا، ومتى، ومن أين.

## ما أُضيف في هذا الإصدار

### الحسابات والصلاحيات (`auth.js`)

أربعة حسابات تُنشأ عند أول تشغيل. الصلاحيات تُفرض على مستوى الـ API لا الواجهة فقط — استدعاء الرابط مباشرة يرجع 403.

| الدور | الصلاحيات |
|---|---|
| سوبر أدمن (مراد عابد) | 13 صلاحية — كل شيء |
| كاشير / كول سنتر / كاستمر كير | `menu.view` + `menu.toggle` فقط |

التمييز دقيق: `PUT /api/items/45` بجسم `{active:false}` مسموح للكاشير، وبجسم `{price:99}` ممنوع — نفس المسار، صلاحية مختلفة حسب الحقل المُعدَّل.

كلمات المرور مشفّرة بـ `scrypt`، والجلسات كوكي `HttpOnly` موقّعة بـ HMAC.

### سجل التغييرات

كل تعديل يحمل ختم صاحبه على الصنف نفسه (`updatedBy`, `updatedRole`, `updatedAt`) بالإضافة لسجل مستقل يحفظ آخر 1500 حدث مع المصدر (لوحة / واتساب / نظام).

### كلمة تفعيل البوت

`requireTrigger` مفعّل افتراضياً — البوت صامت حتى يرسل الزبون `bot` أو `بوت` أو `o2` أو `منيو`. يجعل ربطه برقم شخصي آمناً.

### وضع تصفّح المنيو

`bot` ← كل الأقسام مرقّمة · رقم القسم ← أصنافه بأسعار مصطفّة، تليها الأقسام من جديد · `0` ← إنهاء العملية.

الأرقام للأقسام فقط والدورة مغلقة: بعد كل قسم يُسأل الزبون إن أراد قسماً آخر أو الإنهاء. الطلب يبقى بكتابة اسم الصنف.

### أوامر الطاقم من واتساب

`#دخول` · `#اغلاق` · `#تفعيل` · `#المغلق` · `#خروج_طاقم` — تفاصيلها في SETUP.md.

### لوحة تحكم رسبونسف

كانت بصفر media queries وشريط جانبي ثابت. الآن الشريط ينزلق من زر ☰ دون 900px، والجداول تتحوّل لبطاقات مكدّسة دون 760px، وعناصر التنقّل تُخفى حسب صلاحية الحساب.

## نقاط API الجديدة

```
POST /api/auth/login        تسجيل الدخول
GET  /api/auth/me           الهوية والصلاحيات الحالية
GET  /api/auth/logout       تسجيل الخروج
GET  /api/users             قائمة الحسابات (سوبر أدمن)
PUT  /api/users/:id         تعديل حساب أو كلمة مرور
GET  /api/audit             سجل التغييرات + إحصاءات
POST /api/cats/toggle       تفعيل/إغلاق قسم كامل
```

كل ما تحت `/api/` صار يتطلب تسجيل دخول عدا `/api/auth/login`.

## تحذير أمني

مفتاح خدمة Firebase (`*firebase-adminsdk*.json`) يمنح صلاحية admin كاملة على قاعدة بياناتك. لا يُرفع إلى GitHub أبداً ولا يُوضع داخل مجلد المشروع — مكانه متغير البيئة `FIREBASE_SERVICE_ACCOUNT` فقط.

إن سبق ورُفع ولو مرة، احذفه من Google Cloud Console ← IAM ← Service Accounts وأنشئ غيره. حذفه من GitHub لاحقاً لا يمحوه من سجل الـ commits.

## ما لم يُنجز بعد

- جدولة تلقائية: إغلاق أصناف الإفطار ظهراً وفتحها صباحاً
- تقرير أسبوعي بأكثر الأصناف نفاداً (البيانات موجودة في السجل)
- تثبيت اللوحة كتطبيق على الهاتف (manifest + أيقونة)
